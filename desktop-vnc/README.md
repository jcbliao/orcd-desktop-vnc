# Desktop scripts

See the [setup and usage guide](../README.md) for installation on Engaging and your computer, SSH setup, account configuration, launching, and troubleshooting.

Copy `config.example` to `config.sh` here to set your Slurm resources. No account or QoS is hardcoded. `connect.sh` is the local helper: copy it to `~/connect-desktop.sh` on your computer.
